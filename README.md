# SCIG-Generator-MATLAB
This model facilitates the examination of the dynamic response of the squirrel cage induction generator when directly connected to the grid. Variations in initial speed will be explored, observing stator currents, electromagnetic torque, and rotor speed. Additionally, a comparison will be made between the Simscape induction generator and the Simulink SCIG model developed within this project.
