How to run the model:

1. Open Project2.m, ProjectPlot.m, Final_Model_Project2.slx and Final_Model_Project2_TaskB.slx in MATLAB R2023b
2. Run Project2.m file and value of n_minit = 1450rpm is default in file.
3. Run Final_Model_Project2.slx (Simulink Model)
4. Run ProjectPlot.m (Plot will be generated and stepinfo parameters will be available in command window)
5. Same for Final_Model_Project2_TaskB.slx
6. Repeat the step from 2 to 4 to run the model.
